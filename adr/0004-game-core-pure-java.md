# 0004. game-core — чистая Java-библиотека без Spring

- **Статус:** принято
- **Дата:** 2026-10-01

## Контекст

Правила игры (ТЗ, 4) — самая сложная и самая важная для честности часть системы. Их нужно тщательно тестировать, в том числе редкие сценарии: отключения, резерв, голосование.

## Решение

Все правила, проверки и сокрытие информации живут в отдельной библиотеке game-core без Spring и без ввода-вывода. Ядро — набор функций «состояние + команда → новое состояние или ошибка». Случайность и время передаются снаружи. game-service только доставляет команды в ядро, сохраняет результат и рассылает его.

## Последствия

- Правила тестируются быстрыми модульными тестами, без поднятия Spring и Redis.
- Партии воспроизводимы при одинаковом seed — удобно для отладки и ботов нагрузочного теста.
- Ядро нужно публиковать как зависимость для game-service (GitHub Packages, задача А2) и следить за версиями.
