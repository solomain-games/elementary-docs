# 0006. Дело в MVP — файл в репозитории

- **Статус:** принято
- **Дата:** 2026-10-01

## Контекст

Для MVP достаточно одного дела. Сервис контента с редактором (ТЗ, 10) — большая отдельная работа, которая не нужна для проверки самой игры.

## Решение

Дело описывается JSON-файлом по JSON Schema вместе с изображениями и хранится в приватном репозитории `elementary-cases`. game-service при старте загружает дела из папки. Сервис контента и редактор появятся на этапе 3.

## Последствия

- Можно играть, не дожидаясь админки.
- Формат файла станет основой модели данных content-service и форматом импорта.
- Добавление и правка дела требуют ручной работы и перевыпуска.
- Файлы дела содержат ответы, поэтому репозиторий приватный, а раздаются клиенту только изображения.
