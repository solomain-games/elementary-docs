# 0007. Одна виртуальная машина с Docker Compose и Caddy

- **Статус:** принято
- **Дата:** 2026-10-01

## Контекст

Бюджет на старте — около 5000 ₽ в месяц (ТЗ, 2). Kubernetes и управляемые сервисы Yandex Cloud для MVP избыточны по цене и сложности. Нужны HTTPS, раздача статики и проксирование в шлюз.

## Решение

На этапе 1 всё работает на одной виртуальной машине Ubuntu в Yandex Cloud под Docker Compose. Caddy автоматически получает HTTPS-сертификат, раздаёт фронтенд и изображения, проксирует `/api` и `/ws` в шлюз. Снаружи доступен только Caddy.

## Последствия

- Дёшево и просто, весь стенд описан одним файлом в `elementary-infra`.
- Одна машина — единая точка отказа, обновление без простоя пока невозможно.
- На этапе 6 потребуется пересмотр: несколько экземпляров game-service, балансировка, CDN для медиафайлов, возможно Kubernetes.
