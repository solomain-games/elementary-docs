# 0008. Отдельный репозиторий на сервис, префикс проекта

- **Статус:** принято
- **Дата:** 2026-10-01

## Контекст

Проект состоит из нескольких сервисов, библиотеки, фронтенда, инфраструктуры и контента. Рассматривались монорепозиторий и отдельные репозитории. Для одного разработчика монорепозиторий проще, но одна из целей проекта — научиться практикам многорепозиторной микросервисной разработки. Организация GitHub `solomain-games` общая для всех будущих проектов студии.

## Решение

Каждый сервис и крупная часть проекта живут в отдельном репозитории. Имена репозиториев начинаются с префикса проекта: `elementary-game-core`, `elementary-frontend` и т. д. Локально репозитории лежат в папке `elementary/` под короткими именами. Все репозитории публичные, кроме `elementary-cases`.

## Последствия

- Независимые сборка, версии и деплой каждого сервиса.
- game-core публикуется в GitHub Packages и подключается в game-service как обычная зависимость.
- Изменение протокола затрагивает несколько репозиториев и требует нескольких согласованных PR.
- Настройки (защита ветки, CI) повторяются в каждом репозитории.
