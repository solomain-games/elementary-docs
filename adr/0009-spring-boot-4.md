# 0009. Spring Boot 4

- **Статус:** принято
- **Дата:** 2026-10-01

## Контекст

Бэкенд пишется на Java 25 и Spring Boot (ТЗ, 12). На момент старта проекта доступны две ветки:

- **Spring Boot 3.5** — последняя версия ветки 3, на Spring Framework 6; поддержка заканчивается;
- **Spring Boot 4** — актуальная ветка на Spring Framework 7 и Jackson 3, с полноценной поддержкой Java 25. Spring Cloud выпускается в версиях, совместимых с Boot 4.

## Решение

Все Spring-сервисы проекта (game-service, user-service, gateway и последующие) создаются на актуальной версии Spring Boot 4.x. Версия Boot у всех сервисов одинаковая и обновляется вместе.

## Последствия

- Проект не придётся мигрировать с ветки 3 на 4 через год-два.
- Часть статей, примеров и ответов в интернете написана для Boot 3: названия стартеров, пакеты Jackson (`com.fasterxml.jackson` → `tools.jackson` в Jackson 3) и некоторые настройки могут отличаться. При использовании примеров нужно сверяться с документацией Boot 4.
- game-core не зависит от Spring, но если в нём понадобится Jackson (Я10), его версия должна быть совместима с Boot 4.
